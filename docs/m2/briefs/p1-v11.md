## Fold in (decided; write them as rules)

1. **Settings get a base (platform, drawh).** A settings (`appState`) op names, per key it sets, the `appSeq` it was
   based on. The room applies a key only if its base equals that key's current `appSeq` (compare-and-set); a stale
   key is refused with a **soft** refusal (new code, e.g. `stale-setting`) that only drops that op from the pending
   overlay (no reset, like records in M5), and the client re-reads and may retry. A deliberate revert is a fresh op on
   the current base, so it is distinguishable from a stale save. Fix the "layers lost" known limit accordingly. Say
   how replay treats it (the entry is logged only if applied).
2. **Room identity in welcome (platform, drawh).** `welcome` carries `room: { board, epoch }`; `epoch` increases on
   every rebuild/takeover (persisted with the checkpoint or the lease; say which), so a client knows when the room it
   talks to was rebuilt without guessing from the last entry.
3. **drawh seeding:** renumber only elements the room would refuse (absent from the room AND version > 1,000) to
   **version 1** with a fresh `versionNonce`; send everything else unchanged (platform's test showed 1,000 lets stale
   1,001–2,000 copies overwrite silently).
4. **Authoritative email** wording (§ Tenancy): `email_verified` true AND (`@gmail.com` OR `hd` equals the email's
   domain); gmail does not skip email_verified.
5. **Phase-2 file list:** add packages/protocol/records.js; name the emote set the code ships (read
   packages/protocol/presence.js in the worktree).
6. **Leftovers from docs/m2/reports/p1-seamv.md:** its 2 MEDIUM and 7 LOW (op too big for the bus; pacing "may
   happen" for multi-tab users; id-less refusals; where depth is counted: gateway counts the frame, an op is ≤ 62 deep
   over a socket; crash between createBoard and the owner grant; and the LOWs). Use its suggested fixes unless they
   conflict with 1–5.
7. **Bus cap:** catch-up and snapshots never travel on the bus (gateway reads them from the Store); `.entries`
   batches are split under the 2 MB bus cap (from p4-natss3).
8. **Postgres least privilege** (docs/m2/reports/p4-pgv.md M1): § Store/§ Registry say a server must start with a
   role that does not own the schema (DDL by a separate migrate step, or skipped when the schema exists).
